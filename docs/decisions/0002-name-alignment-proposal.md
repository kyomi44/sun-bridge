# Proposal: align the adopted documents with the Sun Bridge name

Status: proposed, not adopted. Public discussion: [issue 1](https://github.com/kyomi44/sun-bridge/issues/1). This is a name-only amendment; the existing charter and governance remain in effect for the same project.

## Exact proposed changes

In `CHARTER.md`, replace the three occurrences of `Solar Bridge` with `Sun Bridge`: the heading, the opening mission sentence, and the sentence retaining government/utility decision authority.

In `GOVERNANCE.md`, replace the two occurrences of `Solar Bridge` with `Sun Bridge`: the heading and the opening maintainer-led statement.

No other text, authority, employment promise, review requirement, license, or public-data practice changes. The people-first mission and seven-day amendment process remain intact.

## Rationale and implications

The project is now presented as Sun Bridge. Aligning the adopted documents would remove inconsistent branding without changing their meaning. Until adoption, references to Solar Bridge in those documents mean this same project. The name remains a working name, not trademark clearance or affiliation with similarly named businesses.

## Review process

Publish this exact proposal as a clearly labeled public issue. Allow at least seven calendar days from its publication for comment before merging the document changes. Invite operators and other contributors to identify any ambiguity. Then record the comments considered, missing perspectives, final rationale, and approving maintainer in that discussion. No automatic adoption is scheduled.

This file records the proposal; it does not itself amend the adopted charter or governance. Their prior text remains available in repository history.
